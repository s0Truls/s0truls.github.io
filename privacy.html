Privacy Policy

Streamer Watch · Last updated: 8 October 2026

Streamer Watch is a private, self-hosted tool operated by the owner of the YouTube channel The Creator Lobby. It runs only on the owner's own computer and is used only by the owner, to upload videos to the owner's own YouTube channel.

Data accessed through Google and YouTube

When the owner connects their Google account, Streamer Watch uses YouTube API Services (the YouTube Data API) to:

  • upload videos chosen and approved by the owner to the owner's own channel, with the title, description and tags the owner approved;
  • read the connected channel's name and ID, to show which channel is connected.

It does not read, collect or store any information about other YouTube users, viewers or channels.

How data is stored

  • The OAuth access and refresh tokens are stored only on the owner's own computer, in Streamer Watch's local data folder. They are never sent anywhere except to Google to authorize API requests.
  • No data is sold, shared with, or transferred to any third party, and none is used for advertising.
  • Streamer Watch has no server, website account, analytics or cookies.

Google API Services User Data Policy

Streamer Watch's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

Streamer Watch uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Deleting data and revoking access

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Choosing "Disconnect" in Streamer Watch deletes the stored tokens from the owner's computer immediately.
