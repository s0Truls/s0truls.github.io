Streamer Watch

A private, self-hosted tool used by the YouTube channel The Creator Lobby to publish short video clips to its own channel.

What it does

  • Runs only on the channel owner's own computer. It is not a public service and has no other users.
  • Prepares short highlight clips from livestreams, with the streamer credited and linked in every video description.
  • After the channel owner has reviewed and approved a clip, it uploads that clip to the owner's own YouTube channel using the YouTube Data API, with the title, description and tags the owner approved.

How it uses YouTube

  • Signs in only to the channel owner's own Google account, with the owner's consent (OAuth 2.0).
  • Uses the YouTube Data API to upload videos to that channel and to read the channel's name so the owner can see which channel is connected.
  • Does not access, collect or store data about any other YouTube user.

By using this tool, the channel owner agrees to be bound by the YouTube Terms of Service.
